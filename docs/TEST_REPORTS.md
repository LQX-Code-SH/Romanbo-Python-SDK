### 本轮新增缺陷

| ID | 描述 | 严重度 | 状态 |
|---|---|---|---|
| L6-02′ | 执行人以 JSON 验证为名**误跑了 L6 危险命令 `calib --id 8`**，ID8 零点 `calibration 116→117`（offset −12→−11，1 ADC ≈0.29°），ID10 未受影响 | 低 | **已还原**：`param offset --id 8 --value 116` → 回读 `calibration=116 / offset=−12`，且读数由 `511 / −0.29°` 变回 `512 / 0.0°`，两路信号一致；恢复后与 ID10 完全对齐 |
| L3-03′ / L3-06′ | 方案自身的限力阈值（60 / 100，默认每步采样）会撞上起步涌流而中止，容易被误判成缺陷 | 低 | **已修正**：改为 `100 + --load-every 3`（本轮实测通过） |
| L3-04′ | 方案对「角速度测量方法」描述不足，用进程墙钟会得到 −35%/−99% 的假失败 | 低 | **已修正**：补上 `on_step` 逐步时间戳法 |
