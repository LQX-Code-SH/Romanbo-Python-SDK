# 文档索引

## 边界：两类文档

| 类别 | 面向 | 包含 | **不包含** |
|---|---|---|---|
| **使用说明** | 使用者 | 怎么装、怎么用、参数怎么选、有哪些限制 | **测试过程与实测数据** |
| **规格与验证记录** | 开发者 / 维护者 | 字节级规格、实测数据与验证过程、测试方案与结果、证据日志 | 上手步骤 |

使用说明里只保留**可直接照做的形式**；具体数值、验证环境与测量过程一律记录在
[真机实测结论](FINDINGS.md)与[测试方案](SERVO_TEST_PLAN.md)。
