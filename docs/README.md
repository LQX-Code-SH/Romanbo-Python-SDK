## 证据日志

`evidence/` 下的日志由 `tools/servo_probe.py` 采集，文件名含采集时间戳
（`probe-<日期>-<时刻>.log`）。文档中以「日志证明……」表述的结论即引用这些文件，例如：

- `docs/evidence/probe-20260925-221313.log` —— ID 10 的位置限值此时仍为 `(1, 1023)`
- `docs/evidence/probe-20260925-221625.log` —— 3 分钟后变为 `(255, 768)`

两条记录共同说明「位置限值是可写配置，而非型号出厂差异」。

## 阅读约定

- `SERVO_SPEC.md` 用 `✅ / ⚠️ / ❌ / 📖 / 📄` 标记**证据强度**（见其 §0）；
- 其余文档统一区分「**协议文档定义 / 真机实测 / 未验证**」。

两种标记体系含义一致：**未验证的内容绝不写成已验证**，请以标记为准。
